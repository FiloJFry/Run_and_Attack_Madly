# Run and Attack Madly
Run and Attack Madly è uno sparatutto in prima persona incentrato sulle battaglie boss. È un gioco molto essenziale: 0% robaccia da tossici,0% pay-to-win,100% skill,1000% tryhard. Divertiti a sconfiggere i boss più assurdi con le armi più assurde nell'ambiente più assurdo che tu abbia mai visto! 
- GIOCO NON ANCORA TERMINATO
# Come installo il gioco sul computer?
- Clicca il bottone verde "Code" in alto e "Download zip"
- Una volta scaricato lo zip,estrailo
- Per giocare,visita la cartella creata dall'estrazione dello zip e apri il file "index.html" o crea un collegamento sul desktop con quest'ultimo prima di aprirlo
- Buon divertimento!
# P.S. Come creo un collegamento sul desktop col file?
- Assicurati di aver estratto i file dallo zip scaricato da qui col tasto verde "Code"
- Clicca col tasto destro sul desktop,poi su "Nuovo"
- Clicca su "Collegamento"
- Clicca su "Sfoglia" sul pannello così aperto e vai a frugare fra le cartelle del computer finché non trovi quella del gioco
- Una volta trovata,seleziona il file "index.html" della cartella e clicca "Ok",poi "Avanti"
- Digita "Run and Attack Madly" sulla barra di testo quanto ti viene chiesto di assegnare il nome al collegamento
- Clicca su "Fine" ed ammira il gioco finalmente scaricato sul PC!
